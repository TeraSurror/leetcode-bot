Curated lists

A list is just an ordered set of problems. Import one from a CSV and the bot tracks how far through it you are and what to do next — without changing how streaks work.

What a list is (and isn't)

Your solve history is the source of truth for streaks. A list sits alongside it: an ordered set of (slug, title, difficulty) entries. “Progress” is the overlap between your active list and what you've solved.

  • Solving a problem that's on your list advances it automatically — there's no separate “mark done on the list” step.
  • Solving something off-list still counts toward your streak, just not toward that list's percentage.
  • Everyone can be on a different list at the same time. /list next, /list progress, and /streak all act on whichever list is active for that person.

The bot seeds a small 12-problem demo list called starter on first run so /list next works before anyone imports anything.

CSV format

One problem per line: title,slug,difficulty.

  • title — required. The display name, e.g. Two Sum.
  • slug — required. The part of the LeetCode URL after /problems/. For leetcode.com/problems/two-sum/ the slug is two-sum. This is what /list next links to and what solves are matched against.
  • difficulty — optional. Easy / Medium / Hard. Leave the field empty or omit it entirely.
  • A header row starting with title, is skipped automatically.
  • Rows missing a title or slug are ignored. Import order becomes list order.

Worked example

Bringing in a hand-picked set and following it:

  1. Create the list. 
    /list create name:hrt-prep
  2. Import the CSV. Run /list import name:hrt-prep and attach your .csv file as the csv option. The reply reports how many problems were newly added and how many were already there. 
    /list import name:hrt-prep csv:<attach hrt-prep.csv>
  3. Make it your active list. 
    /list switch name:hrt-prep
  4. Work through it. /list next gives your next unsolved problem in import order with its link; /list progress shows solved/total (percent).

Adding more later

/list import appends — run it again against the same list to add more problems. Rows already on the list are skipped, so re-importing an updated CSV only adds the new entries. New problems go on the end, in the order they appear in the file.

Building a CSV for a well-known set

NeetCode 150, Blind 75, and similar lists aren't bundled — that curation is someone else's editorial work, and CSV import is more flexible anyway. To build one:

  • Export or copy the problem list from wherever you follow it.
  • For each problem, take the slug straight from its LeetCode URL (leetcode.com/problems/<slug>/).
  • Put one title,slug,difficulty line per problem in a plain-text .csv and import it.

A spreadsheet with three columns exported as CSV works directly.
