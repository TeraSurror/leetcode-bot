Setup

Getting from a fresh clone to a running bot in your server. About ten minutes, most of it in the Discord developer portal.

Prerequisites

  • Node.js 20 or newer (the package sets "engines": { "node": ">=20" }).
  • A Discord server you can add a bot to (you need Manage Server).
  • For production, a host that can run a long-lived Node process — Railway, Fly.io, a spare always-on machine. The bot listens for slash commands continuously; it is not a cron-only script.

1. Create the Discord application

  1. Go to discord.com/developers/applications → New Application.
  2. Bot tab → Reset Token → copy the token. This is your DISCORD_TOKEN. Keep it secret; anyone with it controls the bot.
  3. The Application ID on the General Information page is your DISCORD_CLIENT_ID.
  4. OAuth2 → URL Generator: check the bot and applications.commands scopes, then under bot permissions check Send Messages and Use Slash Commands.
  5. Open the generated URL in your browser and invite the bot to your server.

2. Get your server and channel IDs

Turn on Developer Mode in Discord (Settings → Advanced → Developer Mode), then:

  • Right-click your server icon → Copy Server ID → DISCORD_GUILD_ID. (Leave blank to register commands globally instead — that can take up to an hour to propagate, so a guild ID is strongly recommended while developing.)
  • Right-click the channel the daily digest should post to → Copy Channel ID → DIGEST_CHANNEL_ID.

3. Configure .env

Copy the example file and fill it in:

cp .env.example .env
VariableRequiredNotes
DISCORD_TOKENyesBot token from the Bot tab.
DISCORD_CLIENT_IDyesApplication ID.
DIGEST_CHANNEL_IDyesChannel the digest is posted to. Must be a text channel the bot can send messages in.
DISCORD_GUILD_IDnoServer ID for fast, dev-only command registration. Blank = global registration.
DIGEST_CRONnoCron expression for the daily digest, in the server's local time. Default "0 8 * * *" (8:00 AM daily).
DB_PATHnoSQLite file path. Default ./data/bot.db, created automatically on first run.
Missing a required variable? The bot throws on startup with the exact name it needs — Missing required environment variable: ….

4. Install, register commands, run

npm install
npm run deploy-commands   # registers /register /solved /streak /list /sync
npm run dev               # starts the bot with tsx

deploy-commands is a one-off script — re-run it only when a command's name, description, or options change. With DISCORD_GUILD_ID set, new commands appear in that server almost immediately.

Production

npm run build   # tsc -> dist/
npm start       # node dist/index.js

Same behaviour, running compiled JavaScript instead of tsx. Deploy dist/ plus node_modules and .env to any host that keeps a Node process alive 24/7. The SQLite file at DB_PATH must live on persistent storage.

5. Smoke test

In your server, run these in order:

  1. /register username:<your-leetcode-username> — links your account.
  2. /solved problem:"Two Sum" difficulty:Easy — logs a manual solve; the reply shows your streak.
  3. /list next — returns the next unsolved problem on the seeded starter list.

Full command details are on the Commands page.
