Commands

Five slash commands. Replies from /register, /solved (when already logged), and /list switch are ephemeral — only you see them.

/register

Link your LeetCode username so the daily auto-check can detect your accepted submissions without you logging them by hand.

OptionRequiredDescription
usernameyesYour exact LeetCode username (case-sensitive, as it appears in leetcode.com/u/<username>).

On registering, the bot does a cheap reachability call to LeetCode. That mainly catches network failures and obvious typos — a wrong-but-well-formed username often just comes back empty rather than erroring, so double-check the spelling.

You can always log solves manually with /solved whether or not you've registered.

/solved

Log a problem you just solved. Instant, manual, and works for anything — not only LeetCode problems.

OptionRequiredDescription
problemyesProblem title, e.g. "Two Sum".
difficultynoOne of Easy, Medium, Hard.

The reply confirms the solve and shows your current streak and active-list progress. Logging the same problem twice on one day is a harmless no-op — you'll get an “already had that logged for today” note.

Slug is guessed from the title. The bot lowercases and hyphenates what you type ("Two Sum" → two-sum). That's consistent enough for streaks and usually matches a list's slug, but unusual phrasing can miss. When it matters, match the title to the one on the problem's LeetCode page.

/streak

Check a current streak and active-list progress.

OptionRequiredDescription
usernoWhose streak to check. Defaults to you.

A streak is your run of consecutive days with at least one solve. A day with no solve yet doesn't break it until the day actually ends — so the count runs back from today if today already has a solve, otherwise from yesterday. Day boundaries are UTC.

/list

Manage and follow curated problem lists. See the Curated lists page for the CSV format and a worked example.

SubcommandOptionsDescription
/list createname (required)Create a new empty list, e.g. name:hrt-prep.
/list importname (required), csv file attachment (required)Append problems to an existing list from a CSV: title,slug,difficulty per line, difficulty optional, a title, header row skipped automatically.
/list switchname (required)Set your active list. Everyone can be on a different list at once.
/list next—Your next unsolved problem on your active list, in import order, with its LeetCode link.
/list progressuser (optional)Completion of the active list as solved/total (percent). Defaults to you.

Importing into a list that doesn't exist tells you to /list create it first. Re-importing rows already on the list is safe — the reply reports how many were new versus already there.

/sync

Run the LeetCode auto-check immediately instead of waiting for the daily pass. No options. The reply says how many linked accounts were checked and how many new solves were found.

How the daily auto-check works

  • Runs once a day on the digest cron (default 0 8 * * * — 8:00 AM in the server's local time), immediately before the digest is posted. /sync runs the same pass on demand.
  • Looks back 26 hours. Each run asks LeetCode for your accepted submissions in the last 26 hours — 24h plus a 2h overlap so a slightly-late run never misses a submission at the boundary.
  • Credits the day you actually solved it. An auto-detected solve is dated by LeetCode's own submission timestamp (in UTC), not by when the check runs. So solving a problem now counts for today even if the check that picks it up runs tomorrow morning.
  • Gap longer than 26 hours → missed. If no auto-check runs within 26 hours of a submission (bot downtime, for instance), the auto path won't see it. Log it with /solved, or run /sync inside the window.
  • Last 20 submissions only. LeetCode's endpoint returns at most 20 recent submissions, so solving 20+ problems between checks can drop the oldest.
  • Manual (/solved) and auto solves write to the same place with a UNIQUE(discord_id, slug, date) constraint, so catching the same solve both ways is a no-op, never a double count.

The daily digest

On the same cron schedule, after the auto-check, the bot posts one embed to DIGEST_CHANNEL_ID: each person's ✅/❌ for the day, what they solved, their streak, and their active-list progress, sorted by streak length. If nobody has any recorded activity, no digest is posted.
